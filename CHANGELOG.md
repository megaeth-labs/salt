# Changelog

All notable changes to salt are recorded here, newest first.
Entries are generated by the release flow from merged PR titles.
Fix wording in the release candidate PR while it is open, or, after it merges, by a PR onto the release branch before settlement is dispatched.
Releases are cut from `release-vX.Y.Z` branches and settled directly on them; the settle dispatch is the approval, gated by the `release` environment.

## v1.1.0

### Features

- add optional reth-codecs encodings for SaltKey and SaltValue ([#160](https://github.com/megaeth-labs/salt/pull/160))

### Fixes

- proof: count a witnessed bucket's used slots once per witness ([#161](https://github.com/megaeth-labs/salt/pull/161))
- salt: allow 2^40 bucket capacity and validate what proofs and witnesses decode ([#150](https://github.com/megaeth-labs/salt/pull/150))

### Performance

- trie: batch fixed-base multiplications over smaller tables ([#165](https://github.com/megaeth-labs/salt/pull/165))
- proof: store witness commitments as indexed affine arrays ([#164](https://github.com/megaeth-labs/salt/pull/164))
- banderwagon: vector MSM for proof checks ([#163](https://github.com/megaeth-labs/salt/pull/163))
- banderwagon: batch witness commitment decoding ([#162](https://github.com/megaeth-labs/salt/pull/162))
- faster witness proofs and proof checks ([#152](https://github.com/megaeth-labs/salt/pull/152))
